# WaterBirdy

WaterBirdy is a small software studio creating tools that help people learn, create, explore, and spend more time doing things they care about.

The goal is simple:

Build software that is useful.
Keep it open when possible.
Favor longevity over growth.

## Current Projects

### OpenSurf

An open-source surf forecasting and ocean conditions platform.

## Sunset Projects

OpenCanopy was sunset in 2026 and has been removed from the WaterBirdy website.

## Notes

WaterBirdy is intentionally small.

No venture funding.
No growth targets.
Just thoughtful software built one project at a time.
